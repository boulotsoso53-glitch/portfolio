Présentation de mes projets informatiques personnels

Bet Arena

Bet Arena est une application personnelle de simulation de paris sportifs développée en Java avec une base de données SQLite.

Présentation du projet

Le projet a été réalisé afin de mettre en pratique différentes compétences en développement Java, en gestion de base de données et en utilisation d'une application en environnement Linux et Windows.

Technologies utilisées

  • Java
  • SQLite
  • JDBC
  • Linux
  • Windows 11

Structure du projet

  • Main.java
  • Database.java
  • sports_betting.sqlite
  • sqlite-jdbc-3.53.4.0.jar
  • BetArena.jar
  • build.sh
  • run.sh
  • reset.sh
  • MANIFEST.MF

Base de données

La base SQLite contient différentes tables permettant de gérer les utilisateurs, les soldes, les événements, les marchés, les sélections, les paris et les transactions.

Fonctionnement

Chaque utilisateur dispose d'un solde initial de 5 000 €. L'application permet de simuler différents paris sportifs et de gérer les opérations liées aux comptes utilisateurs.

Correction et déploiement

Une modification a été réalisée dans le fichier Database.java afin de remplacer un chemin Linux fixe par un chemin relatif vers la base de données.

Le projet a ensuite été reconstruit avec ./build.sh puis testé avec java -jar BetArena.jar sous Linux.

Une version a également été testée sous Windows 11 avec la commande : java -jar .\BetArena.jar.

Rapport du projet Bet Arena

Bet Arena est un projet personnel permettant de simuler une plateforme de paris sportifs. Le projet repose principalement sur Java et SQLite.

L'application utilise une base de données SQLite permettant de stocker les informations relatives aux utilisateurs, aux soldes, aux événements sportifs, aux marchés, aux sélections, aux paris et aux transactions.

Le solde initial d'un utilisateur est fixé à 5 000 €. L'objectif du projet est de permettre de tester différentes fonctionnalités liées à la gestion d'un système de paris dans un environnement contrôlé.

Le projet comprend notamment les fichiers Main.java et Database.java, ainsi que la base sports_betting.sqlite.

Une bibliothèque JDBC SQLite est utilisée pour assurer la communication entre l'application Java et la base de données.

Une difficulté rencontrée concernait le chemin d'accès à la base de données. Le programme utilisait initialement un chemin Linux fixe :

jdbc:sqlite:/home/osboxes/Documents/variable/sports_betting.sqlite

Ce chemin a été remplacé par un chemin relatif :

jdbc:sqlite:sports_betting.sqlite

Cette modification permet de rendre l'application plus facilement transportable et de pouvoir l'exécuter depuis le dossier contenant les fichiers du projet.

Après cette modification, l'application a été reconstruite avec le script build.sh.

Plusieurs tests ont ensuite été réalisés afin de vérifier le fonctionnement de l'application sous Linux puis sous Windows 11.

Sous Windows 11, l'archive BetArena_PC (1).zip a été extraite. Le programme a ensuite été lancé avec :

java -jar .\BetArena.jar

Un avertissement concernant certaines restrictions de méthodes Java et SQLite JDBC pouvait apparaître, mais celui-ci n'empêchait pas le lancement de l'application.

Un raccourci de bureau a également été préparé afin de faciliter le lancement de Bet Arena.

Le dossier final contient le fichier JAR, la base de données, les fichiers sources Java, les scripts de compilation et les différents fichiers nécessaires au fonctionnement du projet.

Ce projet m'a permis de travailler sur le développement Java, la gestion d'une base de données SQLite, la compilation, le déploiement et les tests d'une application dans différents environnements.
