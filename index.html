Compte rendu du projet BET ARENA

BET ARENA est un projet personnel réalisé en autonomie dans le but de concevoir une application de simulation de paris sportifs.

Le projet a permis de travailler sur le développement en Java, la gestion d'une base de données SQLite ainsi que la création d'une interface utilisateur et d'une interface administrateur.

Déroulement et difficultés rencontrées

Le développement de BET ARENA a commencé par la mise en place de l'application et de la base de données SQLite.

Plusieurs tests ont ensuite été réalisés afin de vérifier le fonctionnement de l'application et son lancement sur différents environnements.

Une difficulté rencontrée concernait le lancement de l'application sous Linux et Windows. Le chemin utilisé pour accéder à la base de données devait être adapté afin que l'application puisse fonctionner correctement sur les deux systèmes.

Technologies utilisées

  • Java
  • SQLite
  • HTML
  • CSS
  • JavaScript
