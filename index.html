Capture du projet

Compte rendu du projet BET ARENA

BET ARENA est un projet personnel réalisé en autonomie dans le but de concevoir une application de simulation de paris sportifs.

Le projet a permis de travailler sur le développement en Java, la gestion d'une base de données SQLite ainsi que la création d'une interface utilisateur et d'une interface administrateur.

Déroulement et difficultés rencontrées

Le développement de BET ARENA a commencé par la mise en place de l'application et de la base de données SQLite.

Plusieurs tests ont ensuite été réalisés afin de vérifier le fonctionnement de l'application et son lancement sur différents environnements.

Une difficulté rencontrée concernait le lancement de l'application sous Linux et Windows. Le chemin utilisé pour accéder à la base de données devait être adapté afin que l'application puisse fonctionner correctement sur les deux systèmes.

Technologies utilisées

  • Java
  • SQLite
  • HTML
  • CSS
  • JavaScript

Bilan personnel

Ce projet m'a permis de mettre en pratique mes connaissances en développement informatique et en gestion de bases de données.

J'ai également pu développer mon autonomie, apprendre à résoudre des problèmes techniques et effectuer des tests sur différents environnements.

Situation professionnelle : réseau RJ45

Câblage et test d’une liaison réseau

Contexte

Lors d’un cours pratique au lycée Grieu, j’ai participé à une activité portant sur l’installation et la vérification d’un réseau informatique. L’objectif était de réaliser une liaison réseau entre deux salles et de vérifier son bon fonctionnement.

Activités réalisées

  1. Faire passer des câbles RJ45 d’une salle à une autre.
  2. Relier les câbles aux équipements du réseau.
  3. Effectuer des tests de connexion.
  4. Intervenir au niveau de la baie de brassage.
  5. Tester les différentes connexions présentes dans la baie.
  6. Vérifier que le câblage et les connexions étaient fonctionnels.

Matériel utilisé

  • Câbles réseau RJ45
  • Baie de brassage
  • Équipements réseau
  • Testeur de câble réseau
  • Ordinateur pour vérifier la connexion

Compétences mises en œuvre

  • Réaliser et organiser un câblage réseau
  • Identifier les ports d’une baie de brassage
  • Tester une liaison réseau
  • Vérifier le bon fonctionnement d’une connexion
  • Respecter les consignes
  • Travailler de manière organisée et méthodique

Difficultés rencontrées et bilan

La principale difficulté était d’identifier correctement les câbles et les ports correspondants dans la baie de brassage. Les tests m’ont permis de repérer les problèmes éventuels et de les corriger.

Cette activité m’a permis de mieux comprendre comment est réalisé le câblage d’un réseau informatique et de développer mes compétences pratiques dans les réseaux.
