Présentation d'une situation professionnelle réalisée durant mon Bac Professionnel SN dans le domaine des réseaux.

Situation professionnelle — Réalisation d'une liaison entre 2 salles

Dans le cadre de mon Bac Professionnel SN, j'ai réalisé une situation professionnelle portant sur la réalisation d'une liaison réseau entre deux salles.

Cette activité m'a permis de mettre en pratique mes connaissances dans le domaine des réseaux informatiques, notamment concernant le câblage réseau, les connexions RJ45, le brassage et l'organisation physique d'une liaison réseau.

Objectif de la situation

L'objectif était de réaliser une liaison réseau permettant de relier deux salles afin d'assurer la communication entre les équipements informatiques présents dans les différents espaces.

Cette situation m'a permis de comprendre les différentes étapes nécessaires à la réalisation d'une liaison réseau et l'importance de la qualité du câblage pour obtenir une connexion fiable et fonctionnelle.

Matériel utilisé

  • Câble réseau Ethernet.
  • Connecteurs RJ45.
  • Panneau de brassage.
  • Équipements réseau.
  • Postes informatiques.
  • Outils nécessaires à la réalisation du câblage.

Réalisation de la liaison entre les deux salles

La première étape consiste à préparer correctement le câblage nécessaire à la liaison entre les deux salles.

Les différents conducteurs du câble réseau doivent être organisés correctement afin d'assurer la correspondance des connexions entre les différentes extrémités.

Une attention particulière doit être portée à l'ordre des fils, au raccordement des connecteurs RJ45 et à la qualité du câblage.

Une fois la liaison réalisée, les différents éléments de l'installation peuvent être raccordés afin de permettre la communication entre les équipements des deux salles.

Brassage réseau

Le panneau de brassage permet d'organiser les différentes connexions réseau de l'installation.

La liaison entre les deux salles doit être correctement identifiée et raccordée afin de permettre la communication entre les équipements concernés.

Le brassage permet également de centraliser les connexions et de faciliter la maintenance de l'installation réseau.

Cette partie de la situation m'a permis de mieux comprendre l'organisation physique d'une installation réseau et l'importance du repérage des différentes liaisons.

Vérification et diagnostic

Après la réalisation de la liaison entre les deux salles, il est nécessaire de vérifier que la connexion fonctionne correctement.

En cas de problème, différents éléments peuvent être contrôlés, notamment le câblage, les connexions RJ45, le brassage ou encore les équipements réseau utilisés.

Cette étape permet de mettre en pratique une démarche de diagnostic consistant à rechercher progressivement l'origine d'un éventuel dysfonctionnement.

Projets personnels

Présentation d'un projet personnel réalisé autour du développement Java, d'une base de données SQLite et d'une simulation de paris sportifs.

Bet Arena

Application Java / SQLite de simulation de paris sportifs

Présentation du projet

Bet Arena est un projet personnel consistant à développer une application de simulation de paris sportifs.

L'application a été développée en Java et utilise une base de données SQLite pour enregistrer les utilisateurs, les soldes, les événements, les marchés, les sélections, les paris et les transactions.

L'objectif du projet était de réaliser une application complète permettant de gérer les différentes informations nécessaires au fonctionnement d'une plateforme de simulation.

Technologies utilisées

Java SQLite JDBC Base de données Linux Windows 11

Fonctionnement de la base de données

La base de données SQLite permet de stocker et d'organiser les différentes informations nécessaires au fonctionnement de l'application.

Elle contient notamment les tables suivantes :

  • Utilisateurs
  • Soldes
  • Événements
  • Marchés
  • Sélections
  • Paris
  • Transactions

Solde initial

Lors de la simulation, le compte utilisateur dispose d'un solde initial de 5 000 €.

Adaptation du projet

Lors des tests du projet, le chemin vers la base de données SQLite était initialement configuré avec un chemin absolu spécifique à une machine Linux.

Le chemin a été modifié afin d'utiliser une base de données située directement dans le dossier du projet :

jdbc:sqlite:sports_betting.sqlite

Cette modification permet de rendre l'application plus facilement transportable et de pouvoir l'utiliser depuis différents environnements.

Compilation et lancement

Le projet contient plusieurs fichiers permettant de compiler, lancer et réinitialiser l'application.

  • Main.java
  • Database.java
  • BetArena.jar
  • sports_betting.sqlite
  • sqlite-jdbc-3.53.4.0.jar
  • build.sh
  • run.sh
  • reset.sh
  • MANIFEST.MF

Ce projet personnel m'a permis de mettre en pratique plusieurs compétences en développement informatique, notamment en Java et en gestion de bases de données.
