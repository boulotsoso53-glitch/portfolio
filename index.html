Projets personnels

Présentation de mes projets informatiques personnels

Bet Arena

Bet Arena est une application de simulation de paris sportifs développée en Java avec une base de données SQLite. Le projet permet de simuler un système complet de paris, avec gestion des utilisateurs, des soldes, des événements, des marchés et des transactions.

Java SQLite JDBC Linux Windows 11

Fonctionnalités

  • Gestion des utilisateurs
  • Gestion des soldes
  • Création d'événements sportifs
  • Gestion des marchés
  • Gestion des sélections
  • Placement de paris
  • Gestion des transactions
  • Base de données SQLite

Base de données

La base de données SQLite contient plusieurs tables : users, balances, events, markets, selections, bets et transactions.

Solde initial

Chaque utilisateur dispose d'un solde initial de 5 000 €.

Configuration du projet

Le projet contenait à l'origine un chemin Linux fixe vers la base de données. Celui-ci a été remplacé par un chemin relatif afin de permettre une utilisation plus simple du programme sur différents ordinateurs.

Compilation et tests

  • Compilation avec le script build.sh
  • Lancement avec java -jar BetArena.jar
  • Tests réalisés sous Linux
  • Tests réalisés sous Windows 11
  • Création d'un raccourci bureau

Fichiers principaux

  • Main.java
  • Database.java
  • sports_betting.sqlite
  • sqlite-jdbc-3.53.4.0.jar
  • BetArena.jar
  • build.sh
  • run.sh
  • reset.sh
  • MANIFEST.MF

Rapport du projet Bet Arena

Présentation

Bet Arena est un projet personnel réalisé dans le but de créer une application de simulation de paris sportifs. Le projet utilise Java pour la programmation et SQLite pour la gestion des données.

Architecture

L'application repose sur une architecture comprenant une partie Java permettant de gérer la logique de l'application ainsi qu'une base de données SQLite permettant de stocker les différentes informations.

Gestion des données

Les utilisateurs, les soldes, les événements, les marchés, les sélections, les paris et les transactions sont stockés dans la base de données.

Déploiement

L'application a été compilée puis testée sous Linux. Elle a également été testée sous Windows 11 après extraction de l'archive du projet.

Résultat

Le projet permet de lancer l'application sous forme de fichier JAR et de conserver les données dans une base SQLite.
